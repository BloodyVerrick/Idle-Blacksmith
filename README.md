# Blacksmith's Forge: An Idle Empire

A React-based idle/incremental game where you mine ores, forge items, and build your blacksmith empire!

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app:
   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:5173` to play the game!
